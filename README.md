# ML من الصفر | Machine Learning From Zero

موقع تعليمي تفاعلي: مقدمة في تعلم الآلة (Machine Learning) لمحللي البيانات، بالعامية المصرية ومصطلحات English.

**الموقع المباشر:** https://capwv.github.io/ml-from-zero/

## المحتوى

- 14 درس متدرج من الصفر، آخرهم مشروع نهائي (Capstone) كامل من CSV لتنبؤ
- 56 سؤال كويز بتصحيح فوري + 44 تمرين بالحلول النموذجية
- معمل ML تفاعلي جوه المتصفح (3 تجارب بتحسب فعلياً على جهازك):
  1. **ارسم الخط بنفسك** — Linear Regression: حرك الخط وشوف MSE لحظياً، أو خلي الكمبيوتر يتعلم Least Squares
  2. **K-Means على نقراتك** — Clustering: حط نقط بالماوس وشوف الخوارزمية تشتغل خطوة بخطوة
  3. **عتبة القرار** — Classification: حرك الـ Threshold وشوف Confusion Matrix و Accuracy/Precision/Recall لحظياً
- التقدم بيتحفظ في المتصفح (localStorage)
